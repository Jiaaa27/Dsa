ARRAY

An array is a data structure that can hold a fixed number of values of a single type. The length of an array is established when the array is created. After creation, its length is fixed. Each item in an array is called an element, and each element is accessed by its numerical index.

Types of Arrays

  • Single Dimensional Array
  • Multi Dimensional Array

Single Dimensional Array

A single dimensional array is a linear data structure that stores elements in a sequential manner. It can be visualized as a list of elements where each element can be accessed using its index.
